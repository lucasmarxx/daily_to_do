# Objetivo: Adicionar(e remover) tarefas diárias em uma interface gráfica.

Neste projeto, o objetivo é criar uma janela com utilização da biblioteca <b>CustomTKinter</b>, que permite a adição e remoção de tarefas diárias, algo "trivial" que ajuda muito em uma rotina de estudos =)
